# Roland SP-404SX Emulator for Android

Программная эмуляция легендарного грувбокса/семплера **Roland SP-404SX Linear Wave Sampler** (2009) для операционной системы Android.

Разработано на **Kotlin** с минимальной задержкой воспроизведения (low-latency streaming engine), аутентичным тактильным интерфейсом и полным набором функций оригинального сэмплера.

---

## 🌟 Основные возможности

### 1. Архитектура пэдов и банков
- **12 отзывчивых пэдов** с подсветкой состояний (выключен, загружен, воспроизведение, выбран).
- **3 банка семплов (A, B, C)** — до 36 независимых слотов.
- **Встроенный дефолтный банк A (Boom Bap)**: 12 олдскульных хип-хоп семплов (Kick, Snare, Hi-Hat Closed/Open, Clap, Rimshot, Shaker, Crash, Tom Low/High, Bass Loop, Percussion), работающих сразу "из коробки" без необходимости скачивать что-либо из сети.

### 2. Режимы воспроизведения (Play Modes)
- **TRIGGER**: Классический триггер (однократный запуск).
- **LOOP**: Бесконечный зацикленный луп со стереосинхронизацией.
- **GATE**: Звучит только пока пэд удерживается пальцем.
- **ONE-SHOT**: Семпл доигрывается до конца, не прерываясь.

### 3. Секция управления и перформанса
- **HOLD**: Удержание звучания пэда после отпускания.
- **ROLL**: Дробь/повтор семпла (ролл) с регулировкой частоты через ручку `CTRL 1`.
- **PAD LINK**: Стерео-линкование двух любых пэдов для одновременного запуска.
- **START/END EDIT**: Интерактивная обрезка начала и конца семпла с помощью регуляторов `CTRL 1` (Start) и `CTRL 2` (End) в реальном времени.
- **COPY & DELETE**: Дублирование семплов между пэдами и быстрое безопасное удаление.

### 4. DSP Эффекты (12 оригинальных FX алгоритмов)
Встроенный стереофонический процессор эффектов обработки в реальном времени:
1. **FILTER**: Резонансный State-Variable фильтр (Low-Pass / Band-Pass / High-Pass).
2. **DELAY**: Стереодилей с обратной связью и сатурацией.
3. **REVERB**: Архитектура Шрёдера (4 гребенчатых + 2 аллпасс фильтра).
4. **VINYL SIM**: Фирменная симуляция винила SP-404 (детонация скорости wow/flutter, виниловый шум, щелчки).
5. **COMPRESSOR**: Пиковый компрессор с настраиваемым порогом и make-up gain.
6. **RING MOD**: Кольцевой модулятор с модуляцией несущей частоты.
7. **FLANGER**: Фленджер с модуляцией гребенчатой линии задержки.
8. **PHASER**: 4-каскадный аналоговый фейзер.
9. **ISOLATOR**: 3-полосный DJ-изолятор с полным подавлением полос (-inf dB).
10. **LO-FI**: Биткрашер (с понижением разрядности до 3 бит), sample rate reduction и ламповый овердрайв.
11. **DJFX LOOPER**: Зацикливание аудиосрезов, реверс и эффект скретча.
12. **TAPE ECHO**: Теплый ленточный эхо с сатурацией и плавающим временем задержки.

Все эффекты управляются тремя поворотными энкодерами (**CTRL 1, CTRL 2, CTRL 3**) в реальном времени.

### 5. Секвенсор паттернов (Pattern Sequencer)
- Запись паттернов в реальном времени с поддержкой квантизации (16th notes).
- Автоматическая привязка к музыкальным тактам и регулировка темпа (BPM).
- Визуальная индикация долей такта на ЖК-дисплее.

### 6. Запись с микрофона (Sampling)
- Запись аудио напрямую через встроенный микрофон Android.
- Запись в 44.1 кГц 16-бит PCM WAV.
- Автоматическое назначение записанного семпла на выбранный пэд.

### 7. Файловый менеджер и импорт
- Импорт пользовательских файлов любого формата (**WAV, MP3, AIFF, FLAC, AAC**) через Storage Access Framework (`IMPORT`).
- Автоматическое сохранение и управление семплами во внутреннем хранилище приложения.

### 8. Аутентичный ретро-интерфейс
- Полная детализация корпуса SP-404SX: матовая металлическая текстура, аутентичные шрифты и маркировка.
- Двухстрочный зеленый ЖК-дисплей со сканирующими линиями (scanlines) и стерео VU-метрами.
- Поворотные регуляторы с углом вращения 270° и плавной drag-анимацией.
- Тактильная отдача (виброотклик haptic feedback) при нажатии кнопок и пэдов.

## 🛠️ Сборка проекта

### Требования:
- **Android Studio** Hedgehog / Iguana / Ladybug / Meerkat или новее.
- **Android SDK** API 34+ (поддерживается компиляция с API 36).
- **JDK 17** или выше.

### Сборка через терминал:
```bash
# Клонирование репозитория
git clone https://github.com/ykrop296/SP-404SX.git
cd SP-404SX

# Сборка Debug APK
./gradlew assembleDebug

# Готовый APK будет расположен по адресу:
# app/build/outputs/apk/debug/app-debug.apk
```

## 📱 Установка на устройство

1. Скачайте готовый `SP-404SX-v1.0.apk` из раздела [Releases](https://github.com/ykrop296/SP-404SX/releases).
2. Откройте файл на Android-устройстве (требуется разрешение на установку приложений из внешних источников).
3. При запуске предоставьте разрешение на запись звука (для работы микрофонного семплирования).
